FOODIE - BEGINNER HTML + CSS PROJECT

1. Keep index.html, style.css and the assets folder together.
2. Open index.html in your browser (double-click it).
3. Edit the HTML to change text and sections. Edit style.css to change colours, spacing and layout.

The footer is a Swiggy-inspired multi-column layout using the supplied logo, app-store and social icons. This is a static learning project: demo navigation links and the location/search controls do not have app functionality. No JavaScript is used.
